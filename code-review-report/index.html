6. Ölçümden çıkan somut bulgular (öncelik sırasıyla)

  1. Kapsama %91.0: en zayıf kalanlar calendar (%79.6), dashboard (%85.5) ve platform bağdaştırıcısı notification_platform.dart (ana bilgisayarda çalıştırılamaz).
  2. Bağımlılıklar: 0/11 doğrudan paket ana sürüm geride (go_router 18, flutter_local_notifications 22, flutter_secure_storage 11 vb. güncellendi). Risk: flutter_secure_storage 11 Android'de EncryptedSharedPreferences'ı bıraktı; mevcut kullanıcı verisinin geçişi cihazda doğrulanmadı.
  3. Destek kaydı (support-catalog) girdi doğrulaması ve hız sınırı (CSV injection düzeltildi).
  4. Uzun build metotları: %0.0 metot 60 satırı aşıyor.
  5. Tekrar %2.9: ayrıntı yukarıdaki tabloda.
  6. Git geçmişinde anon JWT (düşük risk, kalıcı).
  7. Kalan (v2 denetimi): edge function hız sınırı ve 3 düşük bulgu, Leaked Password Protection kapalı, backend/edge function davranış testi yok, imzalama/cihaz/iOS/CI doğrulamaları (bölüm 1b).

  • Cihaz/emülatör performansı, açılış süresi, bellek, gerçek frame süresi: ölçülemedi.
