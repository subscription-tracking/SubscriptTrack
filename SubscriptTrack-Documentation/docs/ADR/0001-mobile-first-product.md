# ADR 0001 — Mobil Öncelikli Ürün

## Durum

Accepted

## Bağlam

İlk ürün dokümanı responsive web uygulamasını hedefliyordu. Ürün kararı iOS ve Android mobil uygulama yönünde değişti.

## Karar

Birincil ürün iOS ve Android mobil uygulamadır. Web sitesi tanıtım, SEO, yardım, iptal rehberleri ve yasal işlemler için destekleyici kanaldır.

## Sonuçlar

- Push notification birincil bildirim olur.
- Deep link, offline cache ve mağaza kuralları mimarinin parçasıdır.
- Apple Sign-In ve hesap silme kullanıcı deneyimi dikkate alınır.
- Tam web dashboard MVP zorunluluğu değildir.
