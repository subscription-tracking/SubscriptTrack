# Güvenlik Politikası

SubscriptTrack'te bir güvenlik açığı bulduğunu düşünüyorsan lütfen **herkese açık issue açma**.

- GitHub'da bu deponun **Security** sekmesinden **Report a vulnerability** (özel güvenlik bildirimi) ile bildir.
- Bildirimde etkilenen bölümü, yeniden üretme adımlarını ve olası etkiyi yaz. Gerçek kullanıcı verisine erişme, hizmeti aksatma veya başkalarının hesaplarını test etme.
- Bildirimleri en kısa sürede değerlendirip yanıtlamaya çalışırız; düzeltme yayımlanana kadar ayrıntıyı gizli tutmanı rica ederiz.

Mimari güvenlik ilkeleri: [docs/architecture/SECURITY.md](docs/architecture/SECURITY.md).
