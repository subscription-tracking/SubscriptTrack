# Açık kaynak entegrasyon kararları

Araştırma tarihi 28 Ekim 2026. Mevcut proje: [package.json](../../../expo/package.json) Expo ~57.0.31, React Native 0.86.3, `react-native-svg` 15.15.4, `@expo/vector-icons`; [lockfile](../../../expo/package-lock.json) Reanimated 4.7.1 ve Gesture Handler 3.4.0 için geçişli kayıt içerir. Geçişli kayıt, doğrudan destek veya kurulumun doğru olduğu kanıtı değildir. Önceki [araştırma](../05-open-source-research.md) ayrıntılı lisans sınırlarını içerir.

| Aday / karar | Somut ihtiyaç ve mevcut alternatif | Lisans / SDK 57–RN 0.86 | Android/iOS, native, performans ve bakım |
|---|---|---|---|
| Mevcut shared + RN Animated / **kullan** | Özet, form, ActionSheet ve basit durum geçişleri için [shared/widgets](../../../expo/src/shared/widgets) yeterlilik açısından ilk aday. | Proje kodu; mevcut RN/Expo. | Yeni native binary yok; her iki platformda odak, reduce-motion ve performans yine ölçülmeli. |
| SVG / **mevcut kullan** | Gerçek veri grafikleri veya özel küçük vektör; zaten kurulu `react-native-svg`. | [Expo 57 SVG](https://docs.expo.dev/versions/v57.0.0/sdk/svg/), [kaynak ve lisans](https://github.com/software-mansion/react-native-svg). Paket sürümü mevcut; RN 0.86 cihaz kabulü bu çalışmada yapılmadı. | Mevcut native modül; karmaşık path'ler render maliyeti doğurabilir. Metin alternatifi zorunlu. |
| Lucide / **değerlendir** | Tutarlı çizgi sözlüğü mevcut Material ile sağlanamazsa; alternatif `@expo/vector-icons`. | [ISC lisans](https://github.com/lucide-icons/lucide/blob/main/LICENSE), Feather kökenli bazı ikonlarda MIT bildirimleri; [resmi paket](https://github.com/lucide-icons/lucide). Exact seçilmiş sürüm için SDK 57/RN 0.86 test edilmedi. | SVG bağımlılığı mevcutsa ek native modül gerekmeyebilir; paket/bundle ve iki ikon seti bakımı ölçülmeli. Marka logoları lisansı ayrıca değerlendirilir. |
| FlashList / **ölçüm sonrası değerlendir** | 1000 kayıt kaydırma veya bellek sorunu ölçülürse; alternatif mevcut FlatList. | [MIT kaynak](https://github.com/Shopify/flash-list), [Expo 57](https://docs.expo.dev/versions/v57.0.0/sdk/flash-list/). Sayfa SDK desteğini gösterir; kesin proje sürüm uyumu doğrulanmadı. | Her iki platformda liste davranışı, bellek ve kaydırma ölçülmeli; native/Go ve yeni mimari gereksinimi seçilen sürümde kontrol edilmeli. Varsayımsal hız iddiası yok. |
| Gorhom Bottom Sheet / **yalnız kanıtlı ihtiyaçta** | Sürüklenebilir, klavyeli ve iç içe scroll panel gerekirse; alternatif `ActionSheet` + `LockAwareModal`. | [MIT](https://github.com/gorhom/react-native-bottom-sheet/blob/master/LICENSE), [resmi rehber](https://gorhom.dev/react-native-bottom-sheet/). Reanimated/Gesture Handler peer kombinasyonu SDK 57/RN 0.86 ile doğrulanmadı. | Native gesture/animation bağımlılıkları development build gerektirebilir; focus, screen reader, klavye ve reduce motion bakım maliyeti. |
| Reanimated + Gesture Handler / **değerlendir** | Karmaşık gesture veya UI-thread motion ölçülürse; alternatif Animated/Pressable. | [Reanimated kaynak](https://github.com/software-mansion/react-native-reanimated), [Gesture Handler kaynak](https://github.com/software-mansion/react-native-gesture-handler), [Expo 57 Reanimated](https://docs.expo.dev/versions/v57.0.0/sdk/reanimated/). Açık kaynak lisans ve seçilen alt paket bildirimi sürümde yeniden doğrulanmalı; SDK/RN uyumu kanıtlanmadı. | Native/worklets ve test yapılandırması, build, iki platform ve sürüm yükseltme maliyeti. Lockfile geçişli kayıtları bu kararı karşılamaz. |
| Expo Haptics / **değerlendir** | Onaylı işlemde anlamlı dokunsal geri bildirim testle istenirse; alternatif görsel/erişilebilir duyuru. | [Expo kaynak](https://github.com/expo/expo), [SDK 57 Haptics](https://docs.expo.dev/versions/v57.0.0/sdk/haptics/); seçilen paket lisansı ve sürüm eşleşmesi ayrı doğrulanmalı. | Native modül; Expo Go'da ilgili sürümün bulunması veya dev build şartı kontrol edilmeli. Donanım ve kullanıcı tercihleri farklı; haptic tek geri bildirim olamaz. |
| React Native Paper / **şimdilik reddet** | Tam UI kiti ihtiyacı kanıtlanmadı; mevcut tema/form/ActionSheet var. | [MIT depo](https://github.com/callstack/react-native-paper); SDK 57/RN 0.86 kombinasyonu doğrulanmadı. | Çift tema sistemi, bağımlılık ve görsel geçiş maliyeti; native bağımlılıklar seçilen sürümle doğrulanır. |
| Skia / **şimdilik reddet** | Gelişmiş çizim ihtiyacı yok; SVG + metin alternatifi. | [MIT depo](https://github.com/Shopify/react-native-skia); SDK 57/RN 0.86 kombinasyonu doğrulanmadı. | Native binary/bellek ve platform testi yükü; erişilebilir grafik metni ayrıca gerekir. |

**Kapı:** İzin verici lisanslar ticari kullanıma genel olarak uygundur, ancak seçilen sürüm, dağıtım bildirimi, font/ikon ve geçişli bağımlılık kontrolü olmadan hukuki onay verilmez. Sürüm pinleme, native build/Expo Go uyumu ve performans iddiaları seçilen aday üzerinde Android+iOS doğrulaması gerektirir. Bu aşamada hiçbir paket kurulmadı.
