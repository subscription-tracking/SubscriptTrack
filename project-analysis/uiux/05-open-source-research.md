# Açık kaynak araç araştırması

Araştırma tarihi 2026-10-28. Bu çalışma paket kurmaz. Lisanslar ticari kullanım için genellikle izin verici olmakla birlikte bildirim koşulları, bağımlılıklar, font ve servis logoları seçilen sürümde ayrıca gözden geçirilmelidir; bu belge hukuki onay değildir.

## Mevcut envanter

`expo/package.json`: Expo `~57.0.31`, React Native `0.86.3`, `react-native-svg` `15.15.4`, `@expo/vector-icons`, Hanken Grotesk. `expo/package-lock.json` içinde `react-native-gesture-handler` 3.4.0 ve `react-native-reanimated` 4.7.1 geçişli kayıtları vardır; doğrudan bağımlılık olmadıklarından yapılandırılmış ve uyumlu oldukları varsayılmaz. Haptics, Lucide, FlashList, Bottom Sheet ve Skia doğrudan bağımlılık değildir.
